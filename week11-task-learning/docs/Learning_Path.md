# Learning Path

## Goal
Use this path if you want to learn enough R to understand and rebuild the Week 11 big task yourself.

## Suggested Order
1. Read `Method_Selection_Guide.md` to understand what each required method is doing.
2. Run `../scripts/01_big_task_walkthrough.R` and inspect the outputs it creates.
3. Open `../../week11-project/scripts/week11_project.R` and compare the final version with the walkthrough.
4. Use `../scripts/02_big_task_starter_template.R` to practise writing your own version.
5. Use `Presentation_Outline.md` when turning your analysis into slides or speaking notes.

## What You Should Understand By The End
- how to inspect and clean a dataset in R
- how to justify a hypothesis test
- how to fit and interpret a linear regression model
- how to build a simple classification model
- how to run and explain k-means clustering
- how to turn analysis into presentation-ready outputs

## Best Revision Strategy
- Run the walkthrough once without changing anything.
- Run it a second time and explain each section in your own words.
- Use the starter template and fill in the comments yourself.
- Then use the final project folder when you want the polished version.

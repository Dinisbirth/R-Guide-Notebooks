# Class Notes

This folder contains the class R scripts, small supporting files, and the final Week 11 coursework materials.

## Main Items
- `Week1.R` to `Week8.R`: class exercises and examples.
- `MiniProject.R`: final Week 11 project script.
- `Dashboard (1).R`: dashboard for the jobs dataset.
- `Tabular_DS_Jobs.csv`: raw jobs dataset.
- `Jobs_clean.csv`: cleaned dataset created from the raw jobs data.
- `Week11_BIG_Task.docx`: assessment brief.
- `Week11_Study_Guide.md`: short revision guide.
- `study_outputs/`: extracted brief text and any generated outputs from running the project script.

## Recommended Order
1. Read `Week11_Study_Guide.md`.
2. Run `MiniProject.R`.
3. Review `Jobs_clean.csv` and `study_outputs/`.
4. Run `Dashboard (1).R` if needed.

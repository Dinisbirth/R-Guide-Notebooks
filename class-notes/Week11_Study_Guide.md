# Week 11 Study Guide

## Key Files
- `Tabular_DS_Jobs.csv`: raw dataset for the Week 11 mini-project.
- `MiniProject.R`: final analysis workflow for cleaning, hypothesis testing, regression, classification, and clustering.
- `Jobs_clean.csv`: cleaned dataset created by `MiniProject.R`.
- `Dashboard (1).R`: optional Shiny dashboard built on the cleaned jobs dataset.
- `study_outputs/`: plots and the written summary generated by `MiniProject.R`.

## Week 11 Checklist
- Hypothesis test: independent-samples t-test comparing average salary by Python requirement.
- Linear regression: predicts average salary from rating, company age, skill indicators, seniority, and job type.
- Classification: logistic regression predicts whether a role is a data scientist role.
- Clustering: k-means groups jobs using salary, ratings, company age, and skill indicators.
- Visuals: saved into `study_outputs/` so you have figures ready for revision or presentation.
- Reflection points: assumptions, limitations, and improvements are easiest to discuss from `study_outputs/week11_results_summary.txt`.

## Run Order
1. Make sure the raw file is named `Tabular_DS_Jobs.csv` and is in this folder.
2. Run `MiniProject.R`.
3. Check `Jobs_clean.csv` and the files inside `study_outputs/`.
4. Run `Dashboard (1).R` if you want the optional interactive dashboard.

## What To Revise
- Why the t-test is appropriate:
  Two independent groups, continuous outcome, comparison of mean salary.
- What to say about the regression:
  Focus on coefficient direction, significance, model fit, and diagnostics.
- What to say about the classification model:
  Use confusion matrix, accuracy, precision, recall, specificity, and F1 score.
- What to say about clustering:
  Explain why features were scaled, why `k = 3` was chosen, and how the clusters differ.

## Audience Prep
- Technical audience:
  Mention assumptions, train/test split, diagnostics, and metric definitions.
- Stakeholder audience:
  Focus on salary drivers, skill demand, and what the clusters mean for hiring or targeting.
- Non-technical audience:
  Keep to plain-English patterns such as “Python-linked jobs tend to pay differently” and “jobs fall into a few clear groups.”

## Likely Limitations
- The dataset is not current and may not reflect the latest labour market.
- Some fields use placeholders or unknown categories.
- Rating `0` is treated as missing for modelling.
- Logistic regression gives a simple binary classifier, not the only possible classification approach.

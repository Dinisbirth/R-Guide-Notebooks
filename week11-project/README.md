# Week 11 Project

This folder contains the final mini-project materials for the Week 11 assessment.

## Layout
- `scripts/`: R analysis and dashboard files.
- `data/raw/`: source dataset.
- `data/processed/`: cleaned dataset produced by the analysis workflow.
- `docs/`: assignment brief and revision guide.
- `outputs/`: extracted brief text and generated analytical outputs.

## Run Order
1. Open `scripts/week11_project.R` and run it.
2. Review the cleaned data in `data/processed/`.
3. Review the plots and summary files in `outputs/`.
4. Open `scripts/jobs_dashboard.R` if you want the dashboard.

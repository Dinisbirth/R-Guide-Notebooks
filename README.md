# R Guide Notebooks

Clean R learning repository based on class exercises from `CT7202 Data Analysis and Visualisation Principles`.

## What This Repo Is For
- learning core R step by step
- practising data handling and visualisation
- revising statistics and modelling with simple scripts

## Repository Structure
- [`basics/`](basics): core R syntax, vectors, functions, conditions, loops, and beginner exercises
- [`data-and-visuals/`](data-and-visuals): data cleaning, summaries, filtering, and visualisation examples
- [`statistics-and-models/`](statistics-and-models): hypothesis testing, ANOVA, correlation, regression, and supporting datasets

## Recommended Learning Order
1. Start with [`basics/`](basics).
2. Move to [`data-and-visuals/`](data-and-visuals).
3. Finish with [`statistics-and-models/`](statistics-and-models).

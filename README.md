# R Guide Notebooks

Clean GitHub repository focused only on the Week 11 project and the Week 11 training materials.

## Structure
- [`week11-project/`](week11-project): the final organised project for the Week 11 assessment.
- [`week11-task-learning/`](week11-task-learning): the guided training folder for learning and practising the Week 11 task.

## Recommended Use
1. Start with [`week11-task-learning/README.md`](week11-task-learning/README.md) if you want a guided path.
2. Run [`week11-task-learning/scripts/01_big_task_walkthrough.R`](week11-task-learning/scripts/01_big_task_walkthrough.R) to learn the full workflow.
3. Use [`week11-task-learning/scripts/02_big_task_starter_template.R`](week11-task-learning/scripts/02_big_task_starter_template.R) for your own practice.
4. Move to [`week11-project/`](week11-project) when you want the final polished version.
5. Run [`week11-project/scripts/week11_project.R`](week11-project/scripts/week11_project.R) for the final analysis.
6. Run [`week11-project/scripts/jobs_dashboard.R`](week11-project/scripts/jobs_dashboard.R) for the optional dashboard.

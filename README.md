# R Guide Notebooks

Organised coursework repository for `CT7202 Data Analysis and Visualisation Principles`.

## Structure
- [`class-exercises/`](class-exercises): corrected weekly R scripts and small support files from class.
- [`big-task-learning/`](big-task-learning): guided training pack for learning how to build the Week 11 big task in R.
- [`week11-project/`](week11-project): final assessed mini-project with scripts, data, docs, and outputs.

## Learning Order
1. Start with [`class-exercises/`](class-exercises) if you want the weekly practice material.
2. Use [`big-task-learning/`](big-task-learning) if you want a guided training path for the Week 11 assessment.
3. Use [`week11-project/`](week11-project) if you want the final organised project version.

## Quick Start
1. Review [`big-task-learning/README.md`](big-task-learning/README.md) if you want to learn and practise.
2. Review [`week11-project/docs/Week11_Study_Guide.md`](week11-project/docs/Week11_Study_Guide.md) if you want the final project checklist.
3. Run [`big-task-learning/scripts/01_big_task_walkthrough.R`](big-task-learning/scripts/01_big_task_walkthrough.R) for the guided version.
4. Run [`week11-project/scripts/week11_project.R`](week11-project/scripts/week11_project.R) for the final version.
5. Run [`week11-project/scripts/jobs_dashboard.R`](week11-project/scripts/jobs_dashboard.R) for the optional dashboard.

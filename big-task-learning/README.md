# Big Task Learning

This folder is the training version of the Week 11 big task.

It is designed for:
- learning the required methods step by step
- practising the full workflow before using the final project folder
- helping other people use this repository to train in R

## What To Open First
1. [`docs/Learning_Path.md`](docs/Learning_Path.md)
2. [`docs/Method_Selection_Guide.md`](docs/Method_Selection_Guide.md)
3. [`scripts/01_big_task_walkthrough.R`](scripts/01_big_task_walkthrough.R)
4. [`scripts/02_big_task_starter_template.R`](scripts/02_big_task_starter_template.R)

## What Is In Here
- `docs/`: short learning notes and planning guides
- `scripts/`: a guided walkthrough and a starter template
- `outputs/`: training outputs created when you run the walkthrough script

## Data Source
This folder reuses the main Week 11 dataset from:
- `../week11-project/data/raw/Tabular_DS_Jobs.csv`

That keeps the training folder and the final project folder aligned.
